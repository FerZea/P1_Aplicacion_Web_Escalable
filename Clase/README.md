# Directorio Angular - ejercicio de clase

Proyecto organizado como el ejercicio mostrado por el profesor:

- `src/app/components/controls`: botones y outputs (hijo -> padre)
- `src/app/components/user-card`: tarjeta y input (padre -> hijo)
- `src/app/interfaces`: interfaz `User`
- `src/app/app.ts`: señal `users` y operaciones `sort` / `reverse`

## Ejecutar

```bash
npm install
npm start
```

Abrir `http://localhost:4200`.
